# v0.0.3 nesting changes

- Rotation bounds use the outer contour; placement, preview and DXF export share the same transform.
- Before increasing occupied height, search remaining parts from smallest area upward using all permitted rotations. Contour contact candidates also expose concave pockets and inner holes.
- Bottom-right starts at the lower right and packs left, then upward. Settling respects all four origins. Top-origin rolls trim unused material length.
- Exact contour collision and distance checks preserve margins, spacing, dimensions and direction restrictions. Candidate search is heuristic, not a guarantee of a globally optimal layout.
- Firebase SDK, configuration, rules, authentication and cloud-save UI removed from the application. Remote services were not modified.
- Header version: v0.0.3. For subsequent updates run `npm run version:next` before committing.

Validation:
- `npm run test:cavities`: concave pocket priority, restricted rotation, actual rotated triangle bounds, four corners, translated holes, compaction and roll trimming.
- `npm run test:rotation`: fixed, orthogonal and arbitrary rotation modes.
- `npm test`: real DXF spacing/collision validation plus DXF export regressions.
- `npm run build`: TypeScript and production bundle.
- Existing full-project lint issues remain in DxfViewer effects and curveEngine variable declarations.

On the 32-part DXF fixture, the default single-trial occupied height decreased from 948.713 mm to 944.575 mm. Five trials reached 880.952 mm at 0.3 mm spacing with all 32 parts placed; independently measured minimum separation was 0.300001 mm. Sheet dimensions remain unchanged, so total sheet area efficiency is unchanged; the occupied strip is shorter.
