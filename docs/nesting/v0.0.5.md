# v0.0.5

Closed contours are classified using full polygon containment and boundary intersection checks. A contour crossing a concave outline is no longer assigned as its hole based on one interior sample. Closed source curves belong only to their actual outer/hole part, preserving independent geometry during job creation and export.

Regression coverage includes a triangle whose vertices are inside an L shape but whose edge crosses its notch, complete placement of both parts, nested holes/islands, touching boundaries, curve ownership, and continued rejection of explicitly invalid holes. GLS, Worker cancellation, native DXF clearance, export tests, production build and targeted lint pass.

The reported user's exact failing DXF was unavailable; the existing 32-part reference did not reproduce the error. The regression exercises the confirmed classification defect without disabling validation.
